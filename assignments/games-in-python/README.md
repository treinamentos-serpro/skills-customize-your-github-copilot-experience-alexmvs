
# 📘 Assignment: Python Hangman

## 🎯 Objective

Nesta atividade, você praticará manipulação de strings, loops, condicionais e seleção aleatória ao criar um jogo da Forca interativo em Python.

## 📝 Tasks

### 🛠️ Implementar o jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador tenta descobrir uma palavra oculta, informando uma letra por vez, antes de esgotar as tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Receber um palpite de letra por vez e exibir as letras corretas nas posições correspondentes, usando `_` para as letras ainda não descobertas.
- Exibir o número de tentativas incorretas restantes e atualizá-lo quando o jogador errar.
- Encerrar quando todas as letras da palavra forem descobertas ou quando não houver mais tentativas incorretas.
- Exibir uma mensagem indicando vitória ou derrota.
